# 场景与文档读取规则

## 输入判断顺序

生成回复前，先按以下顺序理解输入：

1. 视频概述：判断视频主要讲哪个方向。
2. 用户评论：判断用户具体痛点、问题、对象和意向强弱。
3. 会话上下文：判断这是首次私信还是后续私信，避免重复问。
4. 用户目标：判断要引导到微信号、企业微信、预约入口、资料包、评估表还是体验。
5. 活动设置：判断本轮是否可以自然使用活动、义诊、优惠券、体验名额等钩子。

## 文档选择规则

- 默认读取 `README.md` 和 `prompts/*.md`。
- 公司主体背景可读取 `相关文档/公司定位与业务总览.md`。
- 评论或视频命中具体业务时，只读取最相关的 1-3 个业务资料。
- 大健康场景必须同时读取 `相关文档/私信合规边界.md`。
- 如果需要给用户下一步动作，可读取 `相关文档/运营活动与承接方式.md`。
- 样本库只用于辅助判断，不要照搬样本话术。

## 信息不足时

- 如果评论太短但视频概述明确，按视频方向轻量承接。
- 如果评论和视频方向都不明确，先用低压力问题确认用户关注点。
- 不要为了凑资料强行匹配业务方向。
