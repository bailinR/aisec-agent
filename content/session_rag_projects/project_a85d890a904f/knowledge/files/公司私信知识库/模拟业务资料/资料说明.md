# 模拟业务资料说明

> 资料性质：AI 模拟资料，供本地私信智能体流程测试使用。上线前必须由业务、法务或项目负责人确认。

## 使用目的

这套资料用于跑通“视频概述 + 用户评论 + 全局提示词 + 场景模板 + 相关知识库 -> 首次私信/私信维护”的完整链路。

## 模拟项目主体

- 公司名称：xx健康科技服务有限公司
- 账号身份：xx健康顾问 / xx品牌客服 / xx账号助理
- 主推方向：睡眠状态初评、大健康膝骨关节干细胞、AI私信引流系统、跨境电商托管
- 承接方式：资料包、免费初步评估、预约入口、草料码、企业微信或微信号

## 资料使用规则

- 可以作为测试回复的事实依据，但不能当作真实业务承诺。
- 涉及价格、名额、疗效、资质、活动时间，必须使用“模拟/待确认/以页面为准”等表达。
- 生成私信时应根据用户评论和视频方向选择最相关资料，不要把所有业务都塞进一条回复。
- 首次私信要完整包含：来意、评论承接、低门槛问题、初步解决方向、甜头/钩子、一个明确下一步。

## 推荐测试评论

- “平时工作压力大，最近老是睡不好。”
- “我妈膝盖上下楼疼，这个有用吗？”
- “这个自动私信系统能接抖音评论吗？”
- “跨境店铺没人运营，你们能托管吗？”
