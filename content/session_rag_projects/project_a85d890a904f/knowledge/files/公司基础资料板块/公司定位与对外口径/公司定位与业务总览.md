# 公司定位与业务总览

默认公司是一家以大健康服务、AI 技术应用和跨境电商运营为核心方向的综合型企业服务团队。公司面向 C 端用户、B 端商家和内部招聘管理场景，提供从内容获客、评论承接、私信沟通到线索分流的整体解决方案。

## 主营业务方向

- 大健康服务：围绕睡眠状态、膝骨关节养护、合规门诊评估和资料包承接，帮助用户完成初步信息整理和预约引导。
- AI 技术应用：围绕评论采集、私信生成、内容生产、智能硬件和自动化运营，为企业提高获客与承接效率。
- 跨境电商运营：围绕 Temu 等平台的新手入驻、选品、定价、物流、流量和违规避坑提供运营资料与托管咨询。
- 招聘与机器人面试：围绕 Boss 沟通、岗位咨询、线上初面和销售招聘流程，辅助 HR 完成候选人初筛。

## 对外表达原则

- 先承接用户提出的具体问题，再介绍相关业务。
- 不把多个业务堆进同一条回复，除非用户主动询问公司整体能力。
- 所有价格、资质、名额、疗效、录用、收益等高风险内容都必须以正式页面、人工确认或合规评估为准。
- 私信阶段优先给出低门槛下一步：资料包、初步评估、演示入口、预约咨询或补充信息。
