## 2. 高意向用户话术（准备购买）

- **意向等级**：高意向  
- **对应关键词**：多少钱 / 报价 / 哪里买 / 有补贴吗 / 求推荐机型 / 一天烘多少吨 / 厂家联系方式  
- **核心钩子**：《热泵低温烘干工艺参数建议表》  
- **私域承接**：企微自动通过 → 发补贴申报指南 + 成本测算表 → 按作物 / 规模建档案 → 当天发案例 / 申报材料，次日邀约上门勘测  

### 话术 A · 直接给价值

- **触发条件**：对方问价格 / 机型 / 补贴  
- **话术正文**：  
  兄弟，看你问机型价格，我整理了一份《热泵低温烘干工艺参数建议表》，含你当地补贴额度、不同吨位回本周期，还有 3 个和你规模相近的本地案例。私信发你，对照着算账少走弯路。  
- **下钩子 & 引导**：报价格式 + 实操参数。私信发精简版 → 主页点「群聊」进群拿完整版（含厂家不给说的能耗实测）。

### 话术 B · 避坑降防备

- **触发条件**：对方求推荐 / 问哪里买  
- **话术正文**：  
  别急着下单！我去年买烘干机踩过坑：同吨位有厂家虚标功率，烘出粮碎粒超 3%。我整理了《热泵低温烘干工艺参数建议表》私发你，对比完再决定。  
- **下钩子 & 引导**：实操参数 + 客户案例。进群看「老客户真实能耗数据」，群置顶联系客服加企微领完整版。

### 话术 C · 算账直击

- **触发条件**：对方问一天烘多少吨 / 回本  
- **话术正文**：  
  兄弟我给你举个例子：300 亩水稻湿粮约 165 吨，遇雨霉变 5% 一吨亏 600 就是近 5 万；热泵吨耗电约 10 块，碎粒从 3% 降到 0.5% 多卖一等粮价差 60 元/吨。详细测算表私发你，进群我帮你做免费霉变风险评估。  
- **下钩子 & 引导**：《免费霉变风险评估》。进群 → 扣对应作物数字 → 企微按标签发专属测算 + 预约勘测。

## 3. 中意向用户话术（犹豫对比）

- **意向等级**：中意向  
- **对应关键词**：热泵好用吗 / 和煤比哪个划算 / 会不会烘坏 / 冬天能用吗 / 耗电高不高 / 和电烘比哪个省  
- **核心钩子**：《免费霉变风险评估》+《专属烘干方案》  
- **私域承接**：企微发实测对比 + 同作物案例 → 第三天问「要不要帮你算回本周期」→ 第 14 天邀约小批量免费试烘  

### 话术 A · 成本打消顾虑

- **触发条件**：对方问和煤 / 电比哪个划算  
- **话术正文**：  
  我之前也纠结煤和电！后来算账：煤炉一年人工 + 煤钱 3 万多，热泵耗电只有电烘 1/4，不用半夜添煤，碎粒从 3% 降到 0.5%，卖价一吨多 60 块。我做个免费烘干成本测算，一看就懂。  
- **下钩子 & 引导**：《免费烘干成本测算》。建了「烘干交流群」每天分享作物烘干技巧，主页群聊进群发完整版。

### 话术 B · 实测建立信任

- **触发条件**：对方问会不会烘坏 / 好用吗  
- **话术正文**：  
  别听厂家吹！我去年烘辣椒温度没调好发白，后来摸索出「三段控温法」，辣度保留 95% 以上，收购商按精选收。我发个霉变风险评估给你，照着调就不会烘坏。  
- **下钩子 & 引导**：《免费霉变风险评估》。进群按作物领对应参数，置顶联系客服加企微发专属手册。

### 话术 C · 冬季 / 能耗答疑

- **触发条件**：对方问冬天能用吗 / 耗电高  
- **话术正文**：  
  奥伯特配喷气增焓 + 智能除霜，-15℃ 照样出热，闭式除湿南方梅雨季反而最省电。热泵能效比 4.0 以上，比电烘省 75%，我发你一份《专属烘干方案》。  
- **下钩子 & 引导**：专属烘干方案。进群看「北方 -15℃ 烘干视频」，企微承接客户信息。

- **意向等级**：低意向  
- **对应关键词**：粮食全霉了 / 晒不过来 / 辣椒又烘白了 / 煤炉要被查 / 晒公路被罚款 / 药材受潮  
- **核心钩子**：《免费烘干成本测算》+ 晒粮 vs 烘干对比  
- **私域承接**：企微发急救方案 + 小户成本测算 → 推共享烘干房 / 租赁信息 → 每周天气预警 + 烘干提醒持续建信任  

### 话术 A · 共情 + 急救

- **触发条件**：对方说粮食霉了 / 晒不过来  
- **话术正文**：  
  兄弟看你家粮食霉了太心疼！我去年遇连阴雨 3 吨玉米发芽亏近 2000。后来用「应急烘干法」，不用买整机，租移动热泵烘 24 小时就能救回。我帮你做个免费烘干成本测算，先止损。  
- **下钩子 & 引导**：免费烘干成本测算。群内每日更新不同天气烘干技巧 + 共享烘干房信息（小户按吨付费），主页群聊进群。

### 话术 B · 损失唤醒

- **触发条件**：对方晒公路 / 被罚 / 煤炉被查  
- **话术正文**：  
  晒公路太危险！邻村去年晒粮被车撞还罚 500。算笔账：雇人翻晒一天 150 晒 3 天 450，还不算霉变；热泵烘一吨才十几块不用盯。我把《晒粮 vs 烘干成本对比表》发你，看哪个划算。  
- **下钩子 & 引导**：晒粮 vs 烘干对比表。进群领「小户租赁 / 共享方案」，企微帮你算租设备还是买设备划算。

### 话术 C · 痛点案例刺激

- **触发条件**：对方辣椒烘白 / 药材受潮  
- **话术正文**：  
  辣椒烘白是温度冲太高辣素跑了。我们三段控温机组红度能回来，收购商按精选收；闭式除湿不熏硫，药材成分保留 95%+。帮你做个免费烘干成本测算，照着来不踩坑。

## 6. 使用说明（喂知识库 / 生成私信时）

1. **先判意向**：用评论关键词匹配高 / 中 / 低意向，再选对应话术 A/B/C。  
2. **钩子要对齐**：高意向主推参数建议表；中意向主推霉变评估 / 专属方案；低意向主推成本测算 / 租赁共享。  
3. **引导链路统一**：私信给精简价值 → 进群拿完整版 / 案例 → 企微算账、试烘或预约勘测。  
4. **异议优先查第 5 节**：客户质疑价格、冬天、操作、补贴、小户、碎粒时，直接套用异议表，勿硬推销整机。  
5. **口径注意**：可讲补贴、实测、共享租赁；勿承诺无法兑现的绝对价格、绝对回本天数或未核实的政策数字。
