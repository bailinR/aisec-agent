# Boss岗位咨询沟通说明

Boss 沟通用于招聘前置咨询，不是正式机器人面试。它更适合候选人刚咨询岗位、询问薪资地点、经验要求、面试安排，或招聘方主动打招呼后的轻量承接。

## 沟通原则

- 先回答候选人的核心问题，再引导补充岗位、经验或到岗时间。
- 不承诺一定录用、一定复试、一定高薪。
- 薪资、福利、社保、岗位要求等内容以正式招聘页面和人工 HR 确认为准。
- 如果候选人愿意继续聊，再引导进入机器人面试或人工 HR。

## 示例方向

候选人问“这个岗位还招吗？”可以先确认还在沟通中，再询问对方应聘岗位和方便沟通时间。候选人问“薪资多少？”可以说明薪资区间以岗位页面为准，并询问过往经验是否匹配。
