# Boss 沟通业务说明

## 当前状态

本业务目录目前是占位目录，暂未配置正式提示词和相关文档。

## 计划用途

后续可用于 Boss 直聘中的非正式初面沟通，例如：

- 候选人刚咨询岗位时的自然回复。
- 候选人询问薪资、地点、经验要求、面试安排时的承接。
- 招聘方主动打招呼后的候选人回复处理。
- 候选人暂时不想细聊、只问简单问题时的轻量沟通。

## 建议目录结构

```text
boss沟通/
  README.md
  prompts/
    全局提示词.md
    岗位咨询回复规则.md
    薪资福利沟通规则.md
  相关文档/
    岗位基础信息.md
    公司介绍.md
    薪资福利与合规.md
```

## 后续维护建议

- 如果要做 Boss 直聘聊天承接，先补充 `prompts/全局提示词.md`。
- 如果要处理岗位咨询，补充 `相关文档/岗位基础信息.md`。
- 如果要处理薪资、福利、社保、录用承诺等问题，补充 `相关文档/薪资福利与合规.md`。
- 该业务和 `机器人面试/` 的区别是：Boss 沟通更偏前置咨询和轻量承接，机器人面试更偏按岗位流程连续提问。
