用户输入 + 全局提示词 + 发送身份 + 业务承接规则 + 流程模板 + 场景材料 + 任务规则提示词 + 活动提示词 + 检索知识 → 最终 Prompt
包含关系：身份由业务、视频概述和活动共同决定；业务承接规则判断用户属于哪个业务、意向强弱和下一步承接动作；流程模板决定回复的话术步骤；场景材料提供当前场景的事实素材；任务规则提示词决定本轮怎么做、按什么流程做、输出什么，以及哪些内容不要说/不要编；活动提示词只有命中时才加入；知识库只取命中文件。
其中，流程模板会优先约束回复步骤，例如首次私信六步引导；场景材料和知识库负责给出可核实的事实支撑，活动钩子负责补上资料、评估、名额或入口。
