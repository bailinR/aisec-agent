# 部署说明

## 2026-07-16 当前正确部署流程

当前项目以 Docker 部署为准。服务器入口为：

- 服务器：`8.217.122.152`
- 项目目录：`/www/wwwroot/aisec-agent-api`
- Web 服务监听：`127.0.0.1:7860`
- 外网入口：`http://8.217.122.152:8091`
- Nginx 代理：`8091 -> 127.0.0.1:7860`

### 总规则

1. 每次部署都先本地重新打包，不要复用旧 tar 包。
2. 服务器解压时必须指定某一个 tar 包名，不要用 `aisec-agent-api-*.tar.gz`。
3. 任何步骤需要切换目录时，必须先执行对应 `cd` 命令。
4. 服务器上不要再用系统 Python 直接跑主服务，以 Docker 容器为准。
5. Docker 容器必须带 `REDIS_URL`，否则任务接口可能连错 Redis 或 Redis DB。
6. Docker 容器必须设置北京时间，否则日志会显示 UTC，和北京时间差 8 小时。
7. Web 服务只负责 API；如果要让私信任务自动执行，还需要启动 worker 容器。

## 1. 本地打包

先切到项目根目录：

```powershell
cd D:\project\sixin\aisec-agent
```

创建打包目录并生成最新 tar：

```powershell
New-Item -ItemType Directory -Force .deploy_build | Out-Null
$ts = Get-Date -Format "yyyyMMdd-HHmmss"
tar --exclude=.git --exclude=.venv --exclude=.deploy_build --exclude=.pytest_cache --exclude='**__pycache__' --exclude='*.pyc' --exclude='*.pyo' --exclude='.tmp-*' --exclude='session-rag-chat*.log' --exclude='.env' --exclude='content/playwright_profiles' -czf ".deploy_build\aisec-agent-api-$ts.tar.gz" .
Get-ChildItem ".deploy_build\aisec-agent-api-$ts.tar.gz"
```

如果是新开的 PowerShell 窗口，先查看最新包：

```powershell
cd D:\project\sixin\aisec-agent
Get-ChildItem .deploy_build\aisec-agent-api-*.tar.gz | Sort-Object LastWriteTime -Descending | Select-Object -First 5
```

## 2. 上传到服务器

仍在本地项目根目录执行。把包名替换成你刚生成的最新包：

```powershell
cd D:\project\sixin\aisec-agent
scp ".\.deploy_build\aisec-agent-api-YYYYMMDD-HHMMSS.tar.gz" root@8.217.122.152:/tmp/
```

## 3. 登录服务器

```powershell
ssh root@8.217.122.152
```

## 4. 服务器解包

先切到临时目录：

```bash
cd /tmp
```

查看最新包：

```bash
ls -lt aisec-agent-api-*.tar.gz
```

解压到项目目录。注意：这里必须使用明确包名：

```bash
tar -xzf aisec-agent-api-YYYYMMDD-HHMMSS.tar.gz -C /www/wwwroot/aisec-agent-api
```

## 5. 切到项目目录

必须先切目录：

```bash
cd /www/wwwroot/aisec-agent-api
```

## 6. 停掉旧服务

旧的 systemd 服务如果还在，会占用 `7860`：

```bash
systemctl stop aisec-api
systemctl disable aisec-api
```

确认端口：

```bash
ss -lntp | grep 7860
```

如果没有输出，说明 `7860` 当前没有被旧进程占用。

## 7. 构建镜像

必须在项目目录执行：

```bash
cd /www/wwwroot/aisec-agent-api
docker build --network=host -t aisec-agent-api:latest .
```

说明：

- `--network=host` 用来减少构建时 DNS 或拉包失败问题。
- Dockerfile 会安装 Python 依赖、Playwright 依赖和 Edge。

## 8. 启动 Web API 容器

必须在服务器执行。把 `你的Redis密码` 换成真实 Redis 密码：

```bash
docker rm -f aisec-agent-api 2>/dev/null || true
docker run -d \
  --name aisec-agent-api \
  --restart unless-stopped \
  --network host \
  -e TZ=Asia/Shanghai \
  -e REDIS_URL='redis://:你的Redis密码@127.0.0.1:6379/11' \
  -v /etc/localtime:/etc/localtime:ro \
  -v /etc/timezone:/etc/timezone:ro \
  -v /www/wwwroot/aisec-agent-api/content:/app/content \
  aisec-agent-api:latest
```

说明：

- `TZ=Asia/Shanghai` 保证日志显示北京时间。
- `REDIS_URL` 当前按 DB `11` 写；如果实际不是 DB 11，必须改成真实 DB。
- 挂载 `content` 用于保留项目配置、任务工件、失败截图等。

## 9. 启动私信任务 worker 容器

如果只启动 Web API，任务可以提交和查询，但不会自动消费 `auto_pending` 队列。

需要自动执行私信任务时，再启动 worker：

```bash
docker rm -f aisec-agent-dm-worker 2>/dev/null || true
docker run -d \
  --name aisec-agent-dm-worker \
  --restart unless-stopped \
  --network host \
  -e TZ=Asia/Shanghai \
  -e REDIS_URL='redis://:你的Redis密码@127.0.0.1:6379/11' \
  -v /etc/localtime:/etc/localtime:ro \
  -v /etc/timezone:/etc/timezone:ro \
  -v /www/wwwroot/aisec-agent-api/content:/app/content \
  aisec-agent-api:latest \
  python -m aisec_agent.worker.douyin_dm_worker --mode send
```

说明：

- Web 容器负责 HTTP API。
- worker 容器负责消费 Redis 任务队列并执行 Playwright。
- 如果任务一直是 `pending / queued`，优先检查 worker 是否已启动。

## 12. 失败截图和定位

任务只有进入失败分支后，才会返回失败原因和截图字段。

常看字段：

- `status`
- `queue_status`
- `error`
- `failure_code`
- `failure_stage`
- `failure_summary`
- `failure_screenshot_url`
- `failure_screenshot_exists`

截图 URL 形如：

```text
http://8.217.122.152:8091/api/v1/douyin/private-message/artifacts/<文件名>
```

如果任务仍是 `pending / queued`：

- 说明任务还没被 worker 消费。
- 此时不会有失败截图。
- 先查 `docker ps` 和 `docker logs --tail=50 aisec-agent-dm-worker`。
