# 私信回复检测 · 私信系统（aisec-agent）开发文档

**版本**：1.0  
**日期**：2026-08-20  
**协作方**：数据中台（comment-kit）

## 1. 职责

提供「单条发出私信是否有对方回复」的检测能力并返回结果。

- **做**：读会话、比对 `expected_outgoing`、返回 `has_reply` / `latest_peer_reply`
- **不做**：线索调度、写中台库、企微通知、未读盯号替代判定

## 2. 已实现接口

### 2.1 主接口

`POST /api/v1/douyin/private-message/conversations/read`

实现模块：`aisec_agent/web/douyin_conversation_read.py`  
入口：`build_douyin_conversation_read_response`

### 2.2 任务复用

`GET /api/v1/douyin/private-message/tasks/{task_id}/replies`

入口：`build_douyin_task_replies_response`（从 Redis 任务取 Cookie/主页/message 后复用主接口逻辑）

### 2.3 契约字段

见 `docs/数据中台对接抖音私信.md` 第 6 节（与中台并行开发冻结契约一致）。

## 3. 检测算法

1. Cookie 或 `account_key` profile 启动 Playwright  
2. 打开目标用户主页 → 点击私信  
3. 采集气泡，标注 `self` / `peer`（角色不明不默认 peer）  
4. 定位匹配 `expected_outgoing` 的我方气泡  
5. 只统计该气泡之后的 peer 文本  
6. `has_reply` / `latest_peer_reply`；找不到锚点则 `outgoing_not_found`，不把历史 peer 当本次回复  

同账号读会话使用进程内锁，避免并发打爆同一 profile。

- 中台将 `pm_task_items.message_content` 作为 `expected_outgoing` 传入  
- 响应经 `_response_envelope` 包装为 `{code,msg,data}`  
- Cookie 不回显  
- 与 `conversation-monitors` 无关，勿混用
