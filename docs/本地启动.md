# 本地启动

日期：2026-08-17

全新 Windows 电脑没有 Python、Redis 等环境时，不要使用本页的开发环境命令。请按 `docs/Windows全新电脑一键部署.md` 从 Gitee 拉取源码，然后双击 `start.bat`；以后启停也只用 `start.bat` / `stop.bat`。

## 1. 启动命令

启动项目默认要同时启动两个进程：

- Web 服务：提供页面、接口、健康检查、任务提交和任务查询。
- worker：消费 Redis 私信任务队列，并执行私信生成和发送。

以后说“启动项目”，默认指 Web + worker 都要启动。只启动 Web 时，`POST /api/v1/douyin/private-message/tasks` 只能把任务写入队列，任务会停在 `pending / queued`，不会真正发送私信。

### 快速启动脚本

便携运行时优先双击项目根目录的 `start.bat`，它会从 Gitee 更新代码、按需安装运行时，并保证只保留一个 `7860` 实例。停止时双击 `stop.bat`。

本地开发优先使用脚本一键启动 Web + worker：

```powershell
cd D:\project\sixin\aisec-agent
powershell -ExecutionPolicy Bypass -File .\scripts\start-local.ps1 -Restart
```

项目内运行时日常启停优先双击 `start.bat` / `stop.bat`。`start.bat` 会拉取当前分支，并使用 `-Restart` 停止旧 Web、worker 和项目 Redis 后启动新版本。`stop.bat` 会停止本项目进程，并清理 `7860` 端口上的监听实例。

默认监听 `0.0.0.0:7860`，本机可以访问 `http://127.0.0.1:7860`，同一局域网设备可以访问脚本输出的 `http://192.168.x.x:7860`。

常用参数：

```powershell
# 启动后自动打开浏览器
powershell -ExecutionPolicy Bypass -File .\scripts\start-local.ps1 -Restart -Open

# 只允许本机访问
powershell -ExecutionPolicy Bypass -File .\scripts\start-local.ps1 -HostAddress 127.0.0.1 -Restart

# 指定端口
powershell -ExecutionPolicy Bypass -File .\scripts\start-local.ps1 -Port 7861 -Restart
```

脚本会自动使用 `.venv\Scripts\python.exe`，没有虚拟环境时回退到系统 `python`，并把 Web 和 worker 日志分别写入 `session-rag-chat.err.log`、`douyin-dm-worker.err.log`。

前台调试时，开两个 PowerShell 窗口，分别在项目根目录执行：

```powershell
cd D:\project\sixin\aisec-agent
.\.venv\Scripts\python.exe -m aisec_agent.web --host 127.0.0.1 --port 7860 --no-open
```

```powershell
cd D:\project\sixin\aisec-agent
.\.venv\Scripts\python.exe -m aisec_agent.worker.douyin_dm_worker --mode send
```

说明：
- `--host 127.0.0.1` 只监听本机回环地址，只能用 `http://127.0.0.1:7860` 或 `http://localhost:7860` 访问。
- 如果要让局域网其他电脑访问，必须改成 `--host 0.0.0.0`，再用本机局域网 IP 访问，例如 `http://192.168.1.70:7860`。

如果没有本地虚拟环境，也可以先尝试：

```powershell
python -m aisec_agent.web --host 127.0.0.1 --port 7860 --no-open
```

另开一个 PowerShell 窗口执行：

```powershell
python -m aisec_agent.worker.douyin_dm_worker --mode send
```

Web 启动成功时日志会出现：

```text
Session RAG chat page: http://127.0.0.1:7860
```

worker 启动成功时日志会出现：

```text
Douyin DM worker started: mode=send once=False
```

## 2. 常用访问地址

- 首页：`http://127.0.0.1:7860`
- 私信生成页面：`http://127.0.0.1:7860/session-rag-chat`
- 文件解析页面：`http://127.0.0.1:7860/file-parser`
- 健康检查：`http://127.0.0.1:7860/api/health`

局域网访问时，把 `127.0.0.1` 换成本机局域网 IP，例如：

- 健康检查：`http://192.168.1.70:7860/api/health`
- 私信任务列表：`http://192.168.1.70:7860/api/v1/douyin/private-message/tasks?limit=20`

前提是服务使用 `--host 0.0.0.0` 启动，并且 Windows 防火墙允许 7860 端口入站。

健康检查正常返回：

```json
{"code":0,"msg":"success","data":null}
```

## 3. 后台启动方式

如果需要在当前 Windows 环境后台启动，并把日志写入文件：

```powershell
cd D:\project\sixin\aisec-agent
$py = Join-Path (Get-Location) ".venv\Scripts\python.exe"
Start-Process -FilePath $py `
  -ArgumentList @("-m","aisec_agent.web","--host","127.0.0.1","--port","7860","--no-open") `
  -WorkingDirectory (Get-Location) `
  -WindowStyle Hidden `
  -RedirectStandardOutput ".\session-rag-chat.log" `
  -RedirectStandardError ".\session-rag-chat.err.log"

Start-Process -FilePath $py `
  -ArgumentList @("-m","aisec_agent.worker.douyin_dm_worker","--mode","send") `
  -WorkingDirectory (Get-Location) `
  -WindowStyle Hidden `
  -RedirectStandardOutput ".\douyin-dm-worker.log" `
  -RedirectStandardError ".\douyin-dm-worker.err.log"
```

如果需要映射到局域网，把 `--host` 改成 `0.0.0.0`：

```powershell
cd D:\project\sixin\aisec-agent
$py = Join-Path (Get-Location) ".venv\Scripts\python.exe"
Start-Process -FilePath $py `
  -ArgumentList @("-m","aisec_agent.web","--host","0.0.0.0","--port","7860","--no-open") `
  -WorkingDirectory (Get-Location) `
  -WindowStyle Hidden `
  -RedirectStandardOutput ".\session-rag-chat.log" `
  -RedirectStandardError ".\session-rag-chat.err.log"

Start-Process -FilePath $py `
  -ArgumentList @("-m","aisec_agent.worker.douyin_dm_worker","--mode","send") `
  -WorkingDirectory (Get-Location) `
  -WindowStyle Hidden `
  -RedirectStandardOutput ".\douyin-dm-worker.log" `
  -RedirectStandardError ".\douyin-dm-worker.err.log"
```

如果只启动了 Web，后续补启动 worker：

```powershell
cd D:\project\sixin\aisec-agent
$py = Join-Path (Get-Location) ".venv\Scripts\python.exe"
Start-Process -FilePath $py `
  -ArgumentList @("-m","aisec_agent.worker.douyin_dm_worker","--mode","send") `
  -WorkingDirectory (Get-Location) `
  -WindowStyle Hidden `
  -RedirectStandardOutput ".\douyin-dm-worker.log" `
  -RedirectStandardError ".\douyin-dm-worker.err.log"
```

## 4. 日志文件

- 标准输出：`session-rag-chat.log`
- 错误和服务日志：`session-rag-chat.err.log`
- worker 标准输出：`douyin-dm-worker.log`
- worker 错误日志：`douyin-dm-worker.err.log`

查看最近日志：

```powershell
Get-Content .\session-rag-chat.err.log -Tail 50
Get-Content .\session-rag-chat.log -Tail 50
```

## 5. 端口与进程检查

检查 `7860` 是否已被占用：

```powershell
Get-NetTCPConnection -LocalPort 7860 -ErrorAction SilentlyContinue |
  Select-Object LocalAddress,LocalPort,State,OwningProcess
```

判断是否已经映射到局域网：

```powershell
Get-NetTCPConnection -LocalPort 7860 -State Listen -ErrorAction SilentlyContinue |
  Select-Object LocalAddress,LocalPort,State,OwningProcess
```

结果含义：
- `127.0.0.1 7860 Listen`：只允许本机访问，局域网访问 `192.168.x.x:7860` 会失败。
- `0.0.0.0 7860 Listen`：监听所有网卡，局域网电脑可以访问本机局域网 IP。

查看本机局域网 IP：

```powershell
Get-NetIPAddress -AddressFamily IPv4 |
  Where-Object { $_.IPAddress -notlike "127.*" -and $_.PrefixOrigin -ne "WellKnown" } |
  Select-Object IPAddress,InterfaceAlias,PrefixLength
```

检查 Python 进程：

```powershell
Get-Process python,python3 -ErrorAction SilentlyContinue |
  Select-Object Id,ProcessName,Path
```

查看 Web 和 worker 的完整启动参数：

```powershell
Get-CimInstance Win32_Process -Filter "Name = 'python.exe'" |
  Where-Object { $_.CommandLine -like "*aisec_agent.web*" -or $_.CommandLine -like "*douyin_dm_worker*" } |
  Select-Object ProcessId,ExecutablePath,CommandLine
```

如果监听是 `0.0.0.0`，本机访问 `http://192.168.x.x:7860/api/health` 正常，但其他电脑仍访问不了，优先检查：
- 两台机器是否在同一局域网或 VPN 网段。
- Windows 防火墙是否允许 7860 端口入站。
- 路由器/AP 是否开启了客户端隔离。

## 6. 和服务器部署的区别

本地启动适合调试页面、接口和知识库配置。

服务器正式运行以 Docker 为准，详见 `docs/部署.md`。正式私信任务要自动执行时，除了 Web API，还要启动 worker 容器，详见 `docs/运行维护与排查.md`。
