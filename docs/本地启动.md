# 本地启动

日期：2026-07-16

## 1. 启动命令

在项目根目录执行：

```powershell
cd D:\project\sixin\aisec-agent
.\.venv\Scripts\python.exe -m aisec_agent.web --host 127.0.0.1 --port 7860 --no-open
```

如果没有本地虚拟环境，也可以先尝试：

```powershell
python -m aisec_agent.web --host 127.0.0.1 --port 7860 --no-open
```

启动成功时日志会出现：

```text
Session RAG chat page: http://127.0.0.1:7860
```

## 2. 常用访问地址

- 首页：`http://127.0.0.1:7860`
- 私信生成页面：`http://127.0.0.1:7860/session-rag-chat`
- 文件解析页面：`http://127.0.0.1:7860/file-parser`
- 健康检查：`http://127.0.0.1:7860/api/health`

健康检查正常返回：

```json
{"code":0,"msg":"success","data":null}
```

## 3. 后台启动方式

如果需要在当前 Windows 环境后台启动，并把日志写入文件：

```powershell
cd D:\project\sixin\aisec-agent
$py = Join-Path (Get-Location) ".venv\Scripts\python.exe"
Start-Process -FilePath $py `
  -ArgumentList @("-m","aisec_agent.web","--host","127.0.0.1","--port","7860","--no-open") `
  -WorkingDirectory (Get-Location) `
  -WindowStyle Hidden `
  -RedirectStandardOutput ".\session-rag-chat.log" `
  -RedirectStandardError ".\session-rag-chat.err.log"
```

## 4. 日志文件

- 标准输出：`session-rag-chat.log`
- 错误和服务日志：`session-rag-chat.err.log`

查看最近日志：

```powershell
Get-Content .\session-rag-chat.err.log -Tail 50
Get-Content .\session-rag-chat.log -Tail 50
```

## 5. 端口与进程检查

检查 `7860` 是否已被占用：

```powershell
Get-NetTCPConnection -LocalPort 7860 -ErrorAction SilentlyContinue |
  Select-Object LocalAddress,LocalPort,State,OwningProcess
```

检查 Python 进程：

```powershell
Get-Process python,python3 -ErrorAction SilentlyContinue |
  Select-Object Id,ProcessName,Path
```

## 6. 和服务器部署的区别

本地启动适合调试页面、接口和知识库配置。

服务器正式运行以 Docker 为准，详见 `docs/部署.md`。正式私信任务要自动执行时，除了 Web API，还要启动 worker 容器，详见 `docs/运行维护与排查.md`。
