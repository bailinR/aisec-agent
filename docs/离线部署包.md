# 离线一键部署包

日期：2026-08-26

用于把 aisec-agent 打成 zip，发给**没有 Git、没有 Python** 的其他 Windows 电脑，解压后双击 `start.bat` 即可运行。

## 1. 在本机构建

### 方式 A：双击构建（推荐）

```text
build-deploy-package.bat
```

选择：

| 选项 | 模式 | 说明 | 体积 |
|---|---|---|---|
| 1 | `lite` | 仅源码 + 知识库；目标机首次 `start.bat` 联网安装运行时 | 约 50–150 MB |
| 2 | `full` | 内置 Python / Redis / Chromium，真正开箱即用 | 约 800 MB–1.2 GB |

### 方式 B：PowerShell

```powershell
cd D:\project\sixin\aisec-agent

# 轻量包（默认）
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-portable-package.ps1

# 完整离线包（需本机已成功 start.bat 过一次，runtime 就绪）
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-portable-package.ps1 -Mode full
```

输出目录：

```text
.deploy_build\aisec-agent-portable-{mode}-{时间}-{commit}.zip
.deploy_build\aisec-agent-portable-{mode}-{时间}-{commit}.sha256
```

## 2. 发给目标电脑

1. 复制 zip（可选附带 `.sha256` 校验文件）
2. 目标机解压到例如 `D:\aisec-agent`
3. 阅读包内 `部署说明.txt`
4. 双击 `start.bat`
5. 打开 `http://127.0.0.1:7860`

## 3. 两种模式怎么选

### lite（轻量包）

- 适合：目标机能联网，带宽尚可
- 首次启动会下载 Python 3.12、Redis、Playwright Chromium
- 与 `docs/Windows全新电脑一键部署.md` 中「Git 拉取后 start.bat」行为一致，只是**不需要 Git**

### full（完整包）

- 适合：内网离线、展会机、客户现场机
- 打包机需先在本机成功运行过 `start.bat`（或 `scripts\install-runtime.ps1`）
- 目标机解压后直接启动，不再下载运行时

## 4. 包内包含 / 不包含

**包含：**

- 全部业务代码、`content/session_rag_projects/` 知识库
- `start.bat` / `stop.bat` / `scripts/`
- `.env.example`、`部署说明.txt`、`PACKAGE_INFO.json`

**不包含（目标机运行后本地生成）：**

- `.env`（含密钥）
- `runtime/logs`、`runtime/state`、`content/playwright_profiles/`
- `.git`、开发缓存

## 5. 目标机要求

- Windows 10/11 **64 位**
- lite 模式：能访问 python.org、PyPI、GitHub（Playwright/Redis 下载）
- 7860 端口未被其他程序长期占用
- 首次监听 `0.0.0.0:7860` 时可能弹出 Windows 防火墙确认

## 6. 校验包完整性（可选）

```powershell
Get-FileHash .deploy_build\aisec-agent-portable-*.zip -Algorithm SHA256
# 与同名 .sha256 文件对比
```

## 7. 与 Git 部署的区别

| 方式 | 需要 Git | 适合场景 |
|---|---|---|
| `git clone` + `start.bat` | 是 | 开发机、长期维护 |
| 离线 zip + `start.bat` | 否 | 交付、拷贝、内网一次性部署 |

更新版本：重新打 zip，解压到新目录（或覆盖后保留 `.env` 与 `runtime/` 再启动）。
