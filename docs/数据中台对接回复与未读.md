# 数据中台对接：未读监控 + 按最近私信查回复

本文约定 **aisec-agent（私信侧）** 与 **comment-kit（数据中台）** 的分工，以及中台应如何调用。

测试地址：`http://127.0.0.1:7860`  
生产替换为 `private_message_provider.send_base_url`（机 23 一般为 `http://192.168.18.100:7860`）。

---

## 分工总览

| 角色 | 负责什么 | 不负责什么 |
|---|---|---|
| **数据中台** | 判定「当前好账号」、调度频率、按最近发送时间筛线索、写回业务状态（未读数 / replied） | 不自己开抖音浏览器 |
| **aisec-agent** | 浏览器执行：开收件箱扫未读、盯号、进会话判断有没有对方回复 | 不维护中台线索表、不决定哪些账号是「好」的 |

两条能力不要混用：

- **未读** = 发送账号收件箱有没有新消息（账号维度）
- **回复检测** = 某条已发出私信之后对方有没有回（线索维度）

---

## 推荐业务流（中台实现）

```
1) 定时：筛「当前好」账号
   └─ 可选先调 verify（活性 + 蓝 V）
2) 未读：对好账号开启/同步盯号，或周期性 inbox 快照
3) 回复：按最近私信时间取 sent 线索，调 batch read
4) 写回：未读数写账号表；has_reply=true 写线索 replied
```

---

## 1. aisec 已提供的接口

| 能力 | 方法 | 路径 |
|---|---|---|
| 账号验活 | `POST` | `/api/v1/douyin/private-message/accounts/verify` |
| 一次性未读快照 | `POST` | `/api/v1/douyin/private-message/accounts/inbox` |
| **批量开启盯号（推荐）** | `POST` | `/api/v1/douyin/private-message/conversation-monitors/sync` |
| 单个盯号启停 | `POST` | `.../conversation-monitors/start` / `stop` |
| 盯号列表（含未读） | `GET` | `/api/v1/douyin/private-message/conversation-monitors` |
| 单条回复检测 | `POST` | `/api/v1/douyin/private-message/conversations/read` |
| **批量回复检测（推荐）** | `POST` | `/api/v1/douyin/private-message/conversations/read/batch` |
| 按任务查回复 | `GET` | `/api/v1/douyin/private-message/tasks/{task_id}/replies` |

兼容路径同时支持 `/api/douyin/...`（无 `v1`）的 sync / batch / inbox / read。

## 2. 中台要做的事

### 2.1 定义「当前好账号」

由中台自己判定，例如同时满足：

- `is_active = 1`
- Cookie 非空
- 验活结果可用（可选：周期性调 `accounts/verify`，`ok=true` 且非 `login_required`）
- 业务上允许监控（未人工停用）

**只把这些账号传给 aisec**，不要把失效/禁用账号 sync 进来。

### 2.2 开启未读监控（账号维度）

推荐两种之一：

**A. 长驻盯号（适合持续监控）**

```http
POST /api/v1/douyin/private-message/conversation-monitors/sync
Content-Type: application/json
```

```json
{
  "accounts": [
    {
      "account_id": "acc_1001",
      "account_name": "发送号A",
      "account_cookie": "sessionid=xxx; sid_guard=xxx"
    }
  ],
  "browser_name": "chrome",
  "headless": true,
  "poll_seconds": 8,
  "stop_missing": false
}
```

说明：

- 默认 **只盯未读**（`generate_reply=false`，`auto_send=false`），不会自动回私信。
- 已在跑的账号会进 `already_running`，不会重复开浏览器。
- `stop_missing=true` 时：本次列表之外的盯号会被停掉（慎用）。
- 之后用 `GET .../conversation-monitors` 读每个账号的 `inbox_unread_count` / `inbox_unread_people`，写回中台账号表。

**B. 一次性快照（适合按钮刷新 / 低频巡检）**

```http
POST /api/v1/douyin/private-message/accounts/inbox
```

扫完就关，不常驻。返回字段含：

- `inbox_unread_count` / `inbox_unread_people`
- **`unread_conversations`**：会话级未读列表（昵称、预览、尽力 `peer_sec_uid`/`peer_profile_url`）
- `clears_unread=false`：不点进会话，尽量不消红点

适合「点一下刷未读」；持续监控仍推荐盯号 + `GET .../conversation-monitors`（快照同样带 `unread_conversations`）。

回复池协作细节见：`docs/回复池协作-私信侧回传.md`。

### 2.3 按最近私信时间查有没有回复（线索维度）

中台侧：

1. 从库中取 `send_status=sent`（或等价状态）线索
2. **按最近发送时间倒序**（`sent_at` / `updated_at`）
3. 可按账号分批；每批建议 ≤10（接口上限 20）
4. 调 batch：

```http
POST /api/v1/douyin/private-message/conversations/read/batch
Content-Type: application/json
```

```json
{
  "account_cookie": "sessionid=xxx; sid_guard=xxx",
  "browser_name": "chrome",
  "headless": true,
  "max_items": 10,
  "items": [
    {
      "lead_id": "lead_88",
      "item_id": "item_88",
      "task_id": "dm_task_xxx",
      "expected_outgoing": "您好，看到您的留言了。",
      "target_profile_url": "https://www.douyin.com/user/MS4wLjABAAAA..."
    }
  ]
}
```

写回规则：

| 返回 | 中台动作 |
|---|---|
| `has_reply=true` | 标 `replied`，写入 `latest_peer_reply` |
| `ok=true` 且 `outgoing_found=true` 且无回复 | 保持 `sent` |
| `ok=false` / `outgoing_found=false` | **不要**标 replied；可记探测失败 |

单条也可用 `POST .../conversations/read` 或 `GET .../tasks/{provider_task_id}/replies`。

## 3. 调用示例（PowerShell）

### 3.1 sync 好账号盯号

```powershell
$body = @{
  accounts = @(
    @{
      account_id = "acc_1001"
      account_name = "发送号A"
      account_cookie = "sessionid=xxx; sid_guard=xxx"
    }
  )
  browser_name = "chrome"
  headless = $true
  poll_seconds = 8
} | ConvertTo-Json -Depth 5 -Compress

Invoke-RestMethod `
  -Uri "http://127.0.0.1:7860/api/v1/douyin/private-message/conversation-monitors/sync" `
  -Method POST -Body $body -ContentType "application/json; charset=utf-8"
```

### 3.2 拉盯号未读

```powershell
Invoke-RestMethod `
  -Uri "http://127.0.0.1:7860/api/v1/douyin/private-message/conversation-monitors" `
  -Method GET
```

### 3.3 批量查最近私信回复

```powershell
$body = @{
  account_cookie = "sessionid=xxx; sid_guard=xxx"
  max_items = 10
  items = @(
    @{
      lead_id = "lead_88"
      expected_outgoing = "您好，看到您的留言了。"
      target_profile_url = "https://www.douyin.com/user/MS4wLjABAAAA..."
    }
  )
} | ConvertTo-Json -Depth 5 -Compress

Invoke-RestMethod `
  -Uri "http://127.0.0.1:7860/api/v1/douyin/private-message/conversations/read/batch" `
  -Method POST -Body $body -ContentType "application/json; charset=utf-8"
```

## 4. 中台调度建议

| 任务 | 建议频率 | 调用 |
|---|---|---|
| 好账号 sync 盯号 | 账号变更后立即 + 每 5～15 分钟兜底 | `conversation-monitors/sync` |
| 读未读写回账号表 | 盯号场景 30s～2min 拉 list；或低频 inbox | `GET monitors` / `POST inbox` |
| 最近 sent 查回复 | 按发送时间，越新越勤（如 5～15 分钟），老线索降频 | `conversations/read/batch` |
| 验活 | 日级或登录失败后 | `accounts/verify` |

注意：

- batch / inbox / verify 都会开浏览器，**按账号串行**，避免同一 Cookie 并发开多个 Playwright。
- 未读人数 **不能** 推断某条线索已回复。
- 禁用账号不要再 sync；Cookie 失效时中台应停盯号并提示重新登录。
